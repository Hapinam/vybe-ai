# Azure Infrastructure — Retired

**Status: Historical infrastructure; not active.**

The original VYBE Azure resources and deployment credentials were retired in November 2026. Scripts in this directory are preserved for historical reference and **may provision billable resources** if executed. Do not run them without explicit authorization and a fresh security/cost review.

The legacy `deploy.sh` can provision Azure resources when explicitly confirmed. Its dry-run default and confirmation guard do not replace owner authorization. Disabling the GitHub workflow does not disable this script.
